= Introduction

The link:https://groovy-lang.org/templating.html#_the_markuptemplateengine[Groovy Markup Template Engine] is primarily aimed at generating XML-like markup (XML, XHTML, HTML5, and others), 
but you can use it to generate any text-based content. The Spring Framework has a built-in integration for using Spring MVC with Groovy Markup.

Spring Boot provides auto-configuration support for Apache FreeMarker. Grace Views Groovy Templates includes `spring-boot-starter-groovy-templates` which uses the Groovy template engine.

Groovy Templates are written in Groovy, end with the file extension `.tpl` and reside in the `app/views` directory.
