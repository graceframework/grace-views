8.3 Configuration

Thymeleaf template configuration can be altered with app/conf/application.yml.

For example:

grails:
    views:
        thymeleaf:
            enabled: true
spring:
    thymeleaf:
        ...

There are a number of spring.thymeleaf properties that can be set if you want to customize the Thymeleaf template engine.

See the Thymeleaf Templating Properties section of the Spring Boot Appendix.
